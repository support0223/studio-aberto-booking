# studio ABERTO 予約システム

studio ABERTO(パーソナルトレーニングジム)の予約フォームです。
重複予約防止・カレンダー登録・お客様自身によるキャンセル・管理者用の予約カレンダーに対応しています。

## 構成

- `index.html` / `style.css` / `app.js` / `config.js` / `assets/logo.png`
  フロントエンド。GitHub Pages などの静的ホスティングでそのまま公開できます。
- `apps-script/Code.gs`
  バックエンド。Google スプレッドシートに紐づけて Google Apps Script のウェブアプリとしてデプロイします。
  予約データの保存、満員判定(同時アクセスでも安全なようロック処理あり)、
  お客様の予約番号+電話番号によるキャンセル、管理者の合言葉チェックをすべてサーバー側で行います。
  お客様の個人情報(名前・メール・電話番号)は、この合言葉チェックを通らないと外に出ません。

## セットアップ手順

### 1. Google スプレッドシート + Apps Script を用意する

1. 新しい Google スプレッドシートを作成する。
2. メニューの「拡張機能」→「Apps Script」を開く。
3. デフォルトで開くコードエディタの中身を全部消し、`apps-script/Code.gs` の内容を貼り付ける。
4. 必要であれば `Code.gs` 冒頭の `ADMIN_PIN`(管理者の合言葉。初期値 `aberto`)を書き換える。
5. 右上の「デプロイ」→「新しいデプロイ」を選択。
6. 種類の選択で「ウェブアプリ」を選ぶ。
7. 「実行するユーザー」= **自分**、「アクセスできるユーザー」= **全員** に設定して「デプロイ」。
8. 発行された URL(`https://script.google.com/macros/s/.../exec` の形)をコピーする。

### 2. フロントエンドに Apps Script の URL を設定する

`config.js` を開き、`REPLACE_WITH_YOUR_APPS_SCRIPT_URL` の部分を手順1でコピーしたURLに書き換える。

### 3. GitHub Pages で公開する

1. GitHubにこのリポジトリを作成し、このフォルダの中身をpushする。
2. リポジトリの Settings → Pages で、公開するブランチ(例: `main`)とフォルダ(`/`)を選択して保存。
3. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される。

## 管理者用ページの開き方

公開されたページ下部にある小さな「Staff」リンクから、合言葉(初期値 `aberto`)を入力すると、
予約カレンダー(予約の一覧・取り消し)が開きます。一度開くと、その端末では次回から自動的に開けます。

## お客様のキャンセル方法

予約完了時に発行される「予約番号」(6桁)と、登録した電話番号を、
フォーム下部の「予約の確認・キャンセルはこちら」から入力するとキャンセルできます。

## データの保存場所

すべての予約データは、手順1で作成したGoogleスプレッドシートの `reservations` シートに保存されます。
直接開いて内容を確認・編集することもできます(ただし手動で編集した内容は次にAppsScript経由で
更新されるまでそのまま残ります)。
